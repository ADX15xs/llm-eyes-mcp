## 排障：首次 tag 推送没触发 workflow
- 现象：首次 `git push origin main v0.1.0`（分支+tag 同一条命令）没触发，但工作流文件正常、state=active。
- 真正根因：**branch 与 tag 在同一次 push 里送出时，tag 触发的 workflow 偶发不派发**（GitHub 已知行为），与仓库 Actions 设置无关。
- 修正方式：删除远端 tag 再单独重推（`git push origin :v0.1.0` + `git push origin v0.1.0`）即触发 Run #1。用户明确未改动任何 repo Settings（我之前误判为 Actions 被禁用，已纠正——那步是多余动作）。
- 教训：发版时**分开推更稳**——先 `git push`（分支），再 `git push origin <tag>`；别把 tag 和分支塞进同一条 push。若再遇「没跑」，先单独重推一次 tag，而不是去怀疑 Settings。
