# 2026-08-05

## 新增 GitHub release 工作流
- 新增 `.github/workflows/release.yml`：push `v*` tag 时触发。
- 流程：`test`(make test) → `build`(matrix 三平台：windows/amd64、linux/amd64、darwin/arm64，零 CGO，ldflags 注入 `main.version=${GITHUB_REF_NAME}`，产出 zip/tar.gz) → `release`(softprops/action-gh-release 挂载产物 + 自动生成 changelog + 生成 checksums.txt)。
- 版本真相源 = git tag；与 Makefile 约定（CGO_ENABLED=0、ldflags）保持一致，未引入 GoReleaser。
- 用户明确选择：自定义工作流 + Makefile 同款 3 平台（未含 darwin/amd64、linux/arm64）。
